# Why there is no front end

The working product is an internal awards database with repeatable commands. Staff can import entries, record human assessments, check missing judging and prepare the panel's records without maintaining an application.

Award Force also provides entrant forms, judge experiences, galleries, communication and payment features. A screen provides participant access, mobile interaction and separation of each judge's work. This base has no public intake, judge login, offline sync, payment processing or public results site. The trusted operator records assessments on behalf of authorised people. One season supports one weighted scoring round.

The HTML views and paperwork are read-only snapshots, refreshed by running their scripts. They cannot change records. Enterprise DNA can build the participant experience, authentication and integrations your programme needs as separately scoped work. The free base does not claim those features already exist.

The database is the product and the coding agent is the way you work with it. AGENTS.md and CLAUDE.md share one command library. Use /new-view for a new read-only report and /customise for a new field or rule.
