# add-season

Run add-season using the current awards records. Read docs/cli.md for this operation.

Use `npm run awards -- add-season` with the required flags from `help`: --code --name --closes --due --owner --actor. Every command accepts --json. Ask for missing human evidence before a mutation. Every change needs --actor and season-scoped changes need --season. Never fabricate records, send messages or publish results.
