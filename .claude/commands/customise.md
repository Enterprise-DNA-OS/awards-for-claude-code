# Customise

Read CLAUDE.md and the existing migrations. Describe the requested field or rule in business terms. Add a new versioned migration under supabase/migrations, update the CLI and relevant views, seed and meaningful tests. Apply with npm run migrate. Never rewrite an applied migration. Preserve historic judging and decisions. Changing a weighted rule after scoring requires a versioned round design. Run npm test and npm run demo, then show the working change. Do not add a front end.
