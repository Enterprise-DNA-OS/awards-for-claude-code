# score

Record only a human-supplied score and rationale. Resolve the entry, judge and criterion before changing anything.

Use `npm run awards -- score` with the required flags from `help`: --season --entry --judge --criterion --value --reason --actor. Every command accepts --json. Ask for missing human evidence before a mutation. Every change needs --actor and season-scoped changes need --season. Never fabricate records, send messages or publish results.
